# Aset hero orisinal

- Berkas: `model-sintetis.png`, PNG 1024 × 1536 dengan alpha transparan.
- Dibuat: 30 September 2026, builtin image generation, mode **generate**, `transparent_background: true`; tanpa gambar referensi.
- Model perempuan dewasa fiktif/sintetis, bukan foto atau representasi siswa nyata. Halaman preview memberi label “Visual ilustratif · model sintetis”. Tidak menyalin iklan atau tokoh tertentu.
- Output asli disalin ke direktori proyek tanpa mengubah piksel. Next.js mengoptimalkan ukuran/format saat penyajian. Bentuk dekoratif dibuat dengan CSS.
- Untuk situs resmi, publisher dapat menggantinya dengan aset sekolah yang sudah disetujui melalui CMS. Preview sintetis otomatis tidak dipakai ketika Supabase telah dikonfigurasi.
